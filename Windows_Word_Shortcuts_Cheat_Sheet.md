# Windows & Microsoft Word Shortcuts

A quick reference for the shortcuts and commands discussed.

---

## 1. Windows + R (`Win + R`) — `shell:` Commands

Press **Win + R**, type the command, and press **Enter**.

| Command | Opens |
|---|---|
| `shell:recent` | Recent files |
| `shell:desktop` | Desktop |
| `shell:downloads` | Downloads |
| `shell:documents` | Documents |
| `shell:personal` | Documents / Personal folder |
| `shell:pictures` | Pictures |
| `shell:videos` | Videos |
| `shell:music` | Music |
| `shell:profile` | Your user folder |
| `shell:home` | Home folder |
| `shell:startup` | Startup folder for your account |
| `shell:common startup` | Startup folder for all users |
| `shell:sendto` | Send To menu |
| `shell:fonts` | Installed fonts |
| `shell:appdata` | Roaming AppData |
| `shell:localappdata` | Local AppData |
| `shell:common appdata` | ProgramData |
| `shell:programs` | Start Menu programs |
| `shell:common programs` | Programs for all users |
| `shell:start menu` | Start Menu |
| `shell:common start menu` | All-users Start Menu |
| `shell:templates` | Templates |
| `shell:favorites` | Favorites |
| `shell:links` | Links / Quick access links |
| `shell:cache` | Internet cache |
| `shell:cookies` | Cookies |
| `shell:history` | Internet history |
| `shell:connectionsfolder` | Network Connections |
| `shell:networkplacesfolder` | Network locations |
| `shell:printersfolder` | Printers |
| `shell:RecycleBinFolder` | Recycle Bin |
| `shell:controlpanelfolder` | Control Panel |
| `shell:AppsFolder` | All installed apps |

## 4. Microsoft Office Application Shortcuts

On supported keyboards / Windows configurations:

| Shortcut | Opens |
|---|---|
| `Ctrl + Shift + Alt + Win + W` | Microsoft Word |
| `Ctrl + Shift + Alt + Win + X` | Microsoft Excel |
| `Ctrl + Shift + Alt + Win + P` | Microsoft PowerPoint |
| `Ctrl + Shift + Alt + Win + O` | Microsoft Outlook |
| `Ctrl + Shift + Alt + Win + N` | Microsoft OneNote |
| `Ctrl + Shift + Alt + Win + T` | Microsoft Teams |

> These special Office shortcuts may depend on the keyboard and Windows/Office configuration.

## 9. Microsoft Word — Special Symbols

In Word, many Unicode codes can be converted by typing the code and pressing **Alt + X**.

| Symbol | Meaning | Word input |
|---|---|---|
| ✓ | Check mark | `2713` + `Alt + X` |
| ✔ | Heavy check mark | `2714` + `Alt + X` |
| ✗ | Cross | `2717` + `Alt + X` |
| ✘ | Heavy cross | `2718` + `Alt + X` |
| ★ | Star | `2605` + `Alt + X` |
| ☆ | Empty star | `2606` + `Alt + X` |
| → | Right arrow | `2192` + `Alt + X` |
| ← | Left arrow | `2190` + `Alt + X` |
| ↑ | Up arrow | `2191` + `Alt + X` |
| ↓ | Down arrow | `2193` + `Alt + X` |
| ↔ | Left-right arrow | `2194` + `Alt + X` |
| ⇒ | Double right arrow | `21D2` + `Alt + X` |
| • | Bullet | `2022` + `Alt + X` |
| ° | Degree | `00B0` + `Alt + X` |
| © | Copyright | `00A9` + `Alt + X` |
| ® | Registered | `00AE` + `Alt + X` |
| ™ | Trademark | `2122` + `Alt + X` |
| ₹ | Indian Rupee | `20B9` + `Alt + X` |
| ± | Plus/minus | `00B1` + `Alt + X` |
| × | Multiplication | `00D7` + `Alt + X` |
| ÷ | Division | `00F7` + `Alt + X` |
| ≠ | Not equal | `2260` + `Alt + X` |
| ≤ | Less than or equal | `2264` + `Alt + X` |
| ≥ | Greater than or equal | `2265` + `Alt + X` |
| ∞ | Infinity | `221E` + `Alt + X` |
| √ | Square root | `221A` + `Alt + X` |
| π | Pi | `03C0` + `Alt + X` |
| Δ | Delta | `0394` + `Alt + X` |
